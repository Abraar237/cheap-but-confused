# Angle A: stale, superseded and updated information in LLM contexts; positional and recency effects in multi-turn agent trajectories

Date: 2026-10-10. Extends section 1 of `00_preemption_sweep_2026-10-10.md`; none of the ids below appear in the sweep. Every id was verified on 2026-10-10 by fetching `https://arxiv.org/abs/<id>` and reading the title and abstract (the arXiv API was rate-limited mid-session, so the abs page was the primary check; Semantic Scholar supplied some venue strings, marked as such). Summaries are written from abstracts; where a claim comes only from a search snippet of the body it is flagged in the row.

## Framing

The sweep already covers lost-in-the-middle, RAG reordering, question-last placement and the two stale-observation agent papers. What it lacks is the literature that explains *why* an append-only history would misread a superseded value, and whether the remedies practitioners reach for (reorder, prune, restate) have precedent. Six strands fill that gap. (1) Knowledge-update work shows that when the same key is revised several times inside one context, models retrieve the first value more reliably than the latest, and the bias grows with the number of updates (2603.12271); conflict benchmarks show two contradictory values are rarely reconciled (2406.13805, 2507.21544), and memory benchmarks find timestamps alone do not convey which version is current (2602.01313). (2) Distractor work has moved into tool settings: irrelevant or noisy tool outputs are over-trusted rather than ignored, tool-side noise hurts more than user-side noise, and more reasoning does not help (2601.07226, 2602.11348, 2605.00136). (3) Goal-drift and long-horizon studies show that a goal fixed at the top of the context loses force as the trajectory grows and that the trajectory itself steers later behaviour (2505.02709, 2603.03258, 2604.11978); the remedies are per-step goal re-injection and a maintained current-state block (2410.02810, 2607.08716, 2610.01415), or folding history away (2510.11967). (4) Multi-turn dialogue work finds that models anchor on early turns and on their own previous outputs, that this self-contamination is a measurable part of the multi-turn gap, and that aggressive history reduction is often accuracy-neutral (2505.06120, 2605.27186, 2602.03664, 2602.24287); position-bias work finds that as inputs lengthen primacy fades but recency holds (2508.07479). (5) Tool-list position matters mostly as primacy in the tool block (2510.00307, 2407.03007), with a counterpoint that tool identity dominates (2605.07990). (6) Mechanism papers tie all of this to causal-mask primacy, RoPE distance decay and attention sinks (2309.17453, 2502.01951, 2508.05128, 2509.12635, 2405.14591, 2510.22752). None of these papers manipulates layout with content held fixed in a tool-using agent, and none accounts for cache hits or billed cost; they supply the mechanism and the priors, not the measurement.

## What this angle implies for the pre-registered directions

**D1 (stale retention hurts L1 and grows with length).** The strongest support is 2603.12271: with several revisions of one key in context, latest-value accuracy falls as revisions accumulate while first-value accuracy stays high, and attention and logit signals on the error cases are flat, so the model is not weighing the candidates so much as failing to separate them. 2510.22752 gives the mechanism at the token level (repeated-key retrieval favours the earliest and latest occurrences and under-retrieves the middle, via induction heads), and 2602.03664 shows that at a fixed environment state, longer histories produce stronger imitation of the model's own earlier actions, which is a length-dependent error channel that does not need any new information to appear. The goal-drift papers (2505.02709, 2603.03258) and the behavioral-state-decay paper (2607.08716) make the same length prediction for the goal rather than the data. The expected shape is therefore: on stale-trap steps L1 falls below L3 and the gap widens from 6 to 18 calls; on neutral steps the gap should be small because nothing in the retained history competes with the answer. Two cautions. First, 2508.07479 predicts that in long inputs far-back items are attenuated rather than misread, so some L1 errors on long episodes may be omissions ('I do not know the current value') rather than stale reads; the audit should code those separately, and the abstention-style error should be reported as its own category. Second, 2601.07226 and 2602.11348 warn that distractor damage in tool settings can be large and is not fixed by prompting, so the distractor factor may produce an L1-L3 gap on neutral steps too; D1's 'no comparable gap on neutral steps' should be stated for the low-distractor condition and tested as an interaction in the high one.

**D2 (reordering helps little).** This angle strengthens the null prior. 2508.07479 shows recency is the stable bias as inputs grow while primacy fades, and in L1 the newest observation and the user turn are already last, so L2's move of 'most relevant last' relocates an item into a slot that the current observation already occupies; the marginal gain is bounded by how often the most relevant prior observation is not the most recent one. The mechanism papers (2502.01951, 2509.12635, 2309.17453) say position effects are real but are a property of distance to the end and of the first tokens, both of which L1 already exploits. 2505.06120 and 2605.27186 locate the multi-turn loss in anchoring on early turns and on the model's own prior outputs, which reordering does not remove because the anchoring content is still present; only pruning (L3) or an explicit override (L4) acts on it. The one optimistic prior for L2 is 2508.05128 (AttnRank), where reordering single-call document lists into high-attention slots improves ten models, and 2410.05983 from the sweep; both are single-call retrieval settings without a multi-turn history and both rewrite the prefix every call. So the expected result is a small, possibly non-significant L2 gain on stale-trap steps, a near-zero gain on neutral steps, and a large cache-read loss; if L2 does beat L1 by a clear margin, 2508.05128 is the citation that predicted it and the explanation would be that the stale competitor was moved away from the end rather than that the current value was moved toward it. For L4 this angle is uniformly favourable: StateAct (2410.02810), the belief-state paper (2610.01415) and EverMemBench's 'version semantics' finding (2602.01313) all point to an explicit current-state line as the thing the history lacks, with the one caution from 2607.08716 that always-on reminders underperform selective ones, which is a cost worth reporting on neutral steps.
